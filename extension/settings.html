Settings

Every img2img setting, saved as you change it. The popup keeps the ones worth changing often — where images are processed, your API key, and the three result settings repeated below.

Results

Open Results in New Tab

Each newly converted image opens in a background tab next to the current one.

Show Icons on Hover

The icons over a converted image (download, show the original, compare, and delete in a result tab) wait until the pointer is over it, instead of showing for as long as the result does. A touch screen has no hover, so leave this off there.

Download Results Automatically

Save each newly converted image as soon as it’s done, like clicking its download button. Results swapped in from the cache aren’t downloaded again.

Download as JPG

Save downloaded images as JPG (smaller files) instead of PNG. Results with transparency stay PNG, and so do results of your own workflows while Keep Workflow in Results is on.

Keep Workflow in Results

Results of your own workflows keep the workflow ComfyUI writes into the image, with the page image, the source images and the settings used, so dropping one into ComfyUI opens the workflow that made it. They then download as PNG, since a JPG can’t carry it.

Double Download

Downloading a result saves the original image as well, next to the result and named like it with -original in place of -img2img, from the download button and with Download Results Automatically. The original is saved as it is, in its own format.

Only for downloads saved as JPG. Balanced is what img2img has always used.

Automatic Selection

Automatic Selection and Auto-process convert every image on a page that qualifies, one after another. Manual Selection and the right-click menu are unaffected by all three.

Images smaller than this on either side are left alone, so thumbnails, avatars and sprites don't cost a job. Raise it on image-heavy sites; lower it if a site's photos are small and nothing happens.

On a page with more images than this, the popup says how many it found and what they cost before starting.

A hard cap for each run, counted per page. The page says so when it stops.

Sites

One site a line. img2img does nothing at all on these: no selection, no right-click item, no Auto-process, no Swap Cache. A site covers its subdomains, and * stands for any part of a host (*.wikipedia.org).

With anything here, Auto-process and Swap Cache only start by themselves on these sites. Manual and Automatic Selection still work everywhere else, when you ask for them.

Pages on these sites open with the workflow named here instead of the one chosen in the popup, so an archive can restore photos while everything else upscales them; another one picked in the popup while on such a page runs there until the page is loaded again. The first rule that covers a site wins.

Cache

How many processed images the cache keeps for Swap Cache and the cached images page. The oldest go first; each one can take a few MB.

Clear the Cache When the Browser Starts

For a shared computer: results are kept only for as long as the browser is open. Results still go to the cache while it runs, because result tabs read them from there.

My ComfyUI

Used when Processing is set to My ComfyUI, which is chosen in the popup. Empty means http://127.0.0.1:8188.

How many images your own ComfyUI is given at the same time. More than one suits a card that finishes a job without using all of it; too many and they only slow each other down. The img2img server always takes one at a time, whatever this says.

Extension

Dark Mode

Dark colours for the popup and every img2img page (cached images, results, My workflows). Until it’s switched, it follows your system.

Announcements

Ask img2img.shop whether there’s anything to tell you, such as a new feature or a problem with the service, and show it at the top of the popup. It asks once a day, and in between only if it hasn’t asked in the last 15 minutes: when you open the popup, and when an image can’t be edited because the img2img service can’t be reached (the message on the page then says if there’s a known problem). The request says nothing about you, your settings or your images, not even which version you have.

Dev Auto-Reload

Reload the extension when tools/dev-reload.js reports a file change. Only for unpacked installs; run the watcher first.
