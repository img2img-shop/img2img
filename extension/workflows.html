My workflows

Add your own ComfyUI workflows to img2img and choose which of their settings appear in the popup. A workflow needs a Load Image node, which gets the image you pick on a page, and a Save or Preview Image node for the result. My workflows run on your own ComfyUI (Processing: My ComfyUI). Like every img2img workflow, each image and each result is checked for adult content, and isn't processed or shown if it's flagged.

Processing is set to the img2img server. My workflows only run with Processing set to My ComfyUI (popup, Settings).
