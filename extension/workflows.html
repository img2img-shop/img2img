My workflows

Add your own ComfyUI workflows to img2img and choose which of their settings appear in the popup. A workflow needs a Load Image node, which gets the image you pick on a page, and a Save or Preview Image node for the result. My workflows run on your own ComfyUI (Processing: My ComfyUI). Like every img2img workflow, each image and each result is checked for adult content, and isn't processed or shown if it's flagged.

Processing is set to the img2img server. My workflows only run with Processing set to My ComfyUI (popup, Settings).

The workflow

Click a node to choose what it does: which Load Image node gets the image from the page, which ones get a source picked in the popup, and which node gives the result. Any other node can get an on/off switch in the popup: switched off, the workflow runs without it. Drag to move around, scroll to zoom, double-click a subgraph to open it.

Settings in the popup

Tick the inputs you want to change from the popup and give them a name. Everything else keeps the value it has in the workflow. A number's range is the node's own unless you narrow it: the popup's slider then covers only the part that's worth having, like -3 to 3 for a LoRA strength the node allows from -10 to 10. A text input can be a dropdown or a slider over choices of your own in place of a text box: a colour to pick from red, blue and green, or a size that slides from small to massive. Each choice has a label for the popup and the text it puts in, so a short label can stand for a long piece of text. The popup always offers None as well, which leaves the input empty.

Order in the popup

Drag a setting to where you want it, or use its arrows.
